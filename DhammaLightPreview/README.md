# Dhamma Light V1.6.1 — Sanitized Build Preview
This is a **test-only preview**, not the full Kids+AR V1.6.1 Android app.

- Native Java Android app with 24 Paṭṭhāna lesson names and short Myanmar meanings
- Two quiz stages per lesson with saved local stars
- Simple Canvas tree metaphor (NOT camera AR)
- Android Myanmar Text-to-Speech when device supports it
- Four YouTube lecture links opening YouTube externally
